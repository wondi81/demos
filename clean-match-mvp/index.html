청소 견적, 업체 3곳까지만 받습니다

요청 한 건에 참여할 수 있는 업체는 3곳. 내 연락처는 참여한 업체에만 열립니다. 고객 윤○○님 시점입니다.

사진은 이 브라우저 안에서만 미리 보입니다. 서버로 전송되지 않습니다.

박
박○○ 계정한 계정 · 역할 2개 (업체 대표, 작업자)
실서비스에서는 서버가 막습니다

실서비스에서는 DB 행 단위 보안(RLS)으로 서버에서 막습니다 — 화면에서 숨기는 방식 아님. 참여하지 않은 업체의 요청에는 연락처 데이터 자체가 내려가지 않습니다.

create policy "참여 업체만 연락처 열람"
on request_contacts for select
using (exists (
  select 1 from bids b
  where b.request_id = request_contacts.request_id
    and b.company_id = my_company_id()
    and b.cancelled_at is null));

정원은 서버 함수가 요청 행을 잠근 뒤 확인합니다. 4곳이 동시에 눌러도 3곳까지만 들어갑니다.

참여 규칙
  • 요청당 정원 3곳, 선착순
  • 참여 즉시 우리 업체에만 고객 연락처 공개
  • 고객이 상담을 시작하기 전까지 참여 취소 가능
  • 취소하면 정원 1곳 즉시 복구, 연락처 다시 잠김
  • 취소한 요청은 재참여 불가 (연락처 열람 남용 방지)
